Check who's really on the other end.

Paste a recruiter's email or domain, upload the offer PDF you received, paste an assessment brief, or enter an offer ID from a QR code. Comes back verified, flagged as a likely scam, or unverifiable.

A sender address alone gets domain + free-provider + recruiter-registry checks. Paste full raw source for SPF/DKIM/DMARC and scam-text scanning too.

VOUCH — COMPANY DASHBOARD

Set up a company so the User tab has something to check against.

Run these in order. Each step needs the company ID from step 1, it fills in automatically once created.

1

Create a company

Registers the company and domain. Returns a DNS TXT record you'd normally set to prove domain ownership.

2

Verify the domain

Real path checks the DNS TXT record. Dev force-verify skips that for a demo, it's marked demo-only in your backend, skip it once you have a real domain.

3

Add a recruiter

Only recruiters added here show as "registered" when a candidate checks an email from this domain, so this is what makes the User tab's email check come back verified.

4

Issue a signed offer

Uploads a PDF, stamps it with a QR code + verification footer, signs it, and stores the record. Download the result and use it in the User tab's PDF check.

5

Scan for lookalike domains

Generates typosquat variants of the company domain and checks which ones actually resolve.
